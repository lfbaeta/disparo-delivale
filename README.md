# Central Inteligente de WhatsApp — Delivale

Projeto **disparo-delivale** preparado para Google AI Studio/GitHub.

## Módulos
- Dashboard
- Envios individuais e fila
- Listas de contatos
- Conversas
- IA Gemini (configuração/prompt/base de conhecimento)
- Evolution API e múltiplas instâncias
- Configurações e logs

## Segurança
As chaves do Gemini e Evolution API não devem ser expostas no frontend. A próxima etapa conecta um backend/banco persistente e webhooks.

## Executar
```bash
npm install
npm run dev
```
